# عدسة برو (AdasaPro) | نظام إدارة مواعيد وحسابات المصورين المحترفين 📸🇱🇾

تطبيق هاتف ويب تقدمي (Mobile-First Web App / PWA) مخصص للمصورين وصناع المحتوى، مصمم بواجهة عصرية فاخرة (Dark Studio Glassmorphism) بالدينار الليبي (**د.ل**).

---

## 🌟 الميزات الرئيسية

- **👥 إدارة مستقلة للزبائن والشركات**:
  - إضافة وتعديل الزبائن مع أرقام هواتفهم وملاحظاتهم.
  - ملف بروفايل مخصص لكل زبون يعرض كافة جلساته السابقة، إجمالي تعاملاته، ومتبقياته المالية.
  - إمكانية إضافة أي عدد من جلسات التصوير لنفس الزبون.

- **📅 تنظيم المواعيد وجدول الجلسات**:
  - تصنيف الجلسات (أعراس، خطوبة، بورتريه، تخرج، منتجات، مؤتمرات).
  - تحديد التاريخ، الوقت، المكان، وحالة الجلسة (مؤكدة، قيد التصوير، قيد التعديل، جاهزة للتسليم، مكتملة).
  - تخزين روابط تسليم الصور السحابية (Google Drive / WeTransfer).

- **💰 الإدارة المالية الدقيقة بالدينار الليبي (د.ل)**:
  - حساب السعر الكلي، المقبوض، المتبقي، أجور المساعدين، والمصاريف التشغيلية.
  - حساب صافي أرباح المصور الحقيقية تلقائياً.
  - **حماية صارمة من تجاوز المتبقي**: منع تسجيل أي دفعة تتجاوز الرصيد المتبقي على الزبون برمجياً مع تحذير مرئي.
  - **سجل تاريخ الدفعات (Payment History)**: توثيق زمني لكل عربون ودفعة دفعها الزبون مع التاريخ وطريقة الدفع (كاش، تحويل مصرفي، صك).

- **💬 فواتير وتذكيرات واتساب فورية**:
  - إرسال تفاصيل الحجز والفاتورة للزبون بضغطة زر واحدة عبر واتساب.
  - قوالب جاهزة لتأكيد الحجز، تذكير بموعد الجلسة، وإشعار جاهزية الصور.

- **🎒 حقيبة المصور**:
  - قائمة فحص وتجهيز المعدات (Gear Checklist).
  - حاسبة تسعير الجلسة الذكية بالدينار الليبي.
  - نسخ احتياطي واستيراد وتصدير قاعدة البيانات بصيغة JSON.

## 🚀 كيفية التشغيل محلياً

لا يحتاج التطبيق إلى أي إعدادات معقدة؛ فهو مبني بتقنيات الويب القياسية (HTML5 / Vanilla CSS3 / Vanilla JavaScript).

1. افتح المجلد في أي خادم محلي، مثلاً باستخدام بايثون:
   ```bash
   python -m http.server 8080
   ```
2. افتح المتصفح على الرابط:
   ```
   http://localhost:8080
   ```

## 📂 هيكل المشروع
- `index.html`: واجهة التطبيق، الشاشات، والنوافذ التفاعلية.
- `style.css`: نظام التصميم الفاخر والتأثيرات الزجاجية والأنماط المتجاوبة.
- `app.js`: محرك التطبيق، إدارة الحالات، الحسابات المالية، والتحقق الصارم.
- `README.md`: الدليل التعريفي للمشروع.
